# ground-effect-airplane# CFD Studies (ANSYS Fluent) — Ground Effect & Transonic Shock

## Overview
This repository contains short academic CFD studies developed with **ANSYS Fluent**:
- **Ground effect** study on a commercial aircraft configuration (external aerodynamics near a ground plane).
- **Transonic airfoil** study showing **shock-wave formation**.

Figures are in `docs/figures/`. Numerical results and plots are provided in `results/` (Excel).

## Studies
### 1) Ground Effect — Commercial Aircraft Configuration
**Goal:** evaluate how ground proximity modifies the flow field and aerodynamic trends.

**Outputs (examples):**
- Mesh overview and refinement near the body/ground
- Trends of coefficients (CL/CD/Cm) vs a normalized height parameter (see figures)
- Cp distributions at selected wing sections

### 2) Transonic Airfoil — Shock Wave Visualization
**Goal:** visualize transonic flow features and shock-wave formation using pressure/Mach-related contours.

## Files
- `docs/figures/` — screenshots (mesh, contours, response surface, plots)
- `results/` — Excel with tables/plots used to summarize results
